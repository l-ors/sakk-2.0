# Sakk 2.0

A klasszikus sakk újragondolása, nagyobb táblával, egy új bábuval és az eredeti figurák újragondolásával.

A projektet 1 óra 30 perc alatt készítettem, Claude Code-ot használva.

A használt promptok elérhetők a `prompts.txt` fájlban. Ezek tartalmazhatnak elírásokat, helytelen fogalmazásokat, főleg a vége felé, amikor már kevés időm volt. Magyarul (AI által fordítva) a `prompts-hu.txt` fájlban érhetők el az utasítások.
